# Student Management System

A simple console-based Student Management System project developed using Core Java.  
This project helps to manage student details such as adding, viewing, updating, and deleting student records.

## Features
- Add Student
- View All Students
- Search Student
- Update Student Details
- Delete Student
- Menu-driven console application
- Uses ArrayList for data storage

## Technologies Used
- Java
- OOP Concepts
- ArrayList
- Scanner Class

## Concepts Practiced
- Classes and Objects
- Constructors
- Encapsulation
- Method Creation
- Loops and Conditional Statements
- Collections Framework
- Exception Handling (if used)

## Project Structure
- `Student.java` → Student model class
- `StudentManagementSystem.java` → Main application logic

## How to Run
1. Clone the repository
2. Open the project in any Java IDE
3. Compile and run the `StudentManagementSystem.java` file

## Future Improvements
- File Handling for data storage
- Database connectivity using JDBC
